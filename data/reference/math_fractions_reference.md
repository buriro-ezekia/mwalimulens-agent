# Synthetic classroom reference — MATH-FRACTIONS

This file is synthetic classroom reference material for the MwalimuLens challenge demo.
It is **not learner evidence** and must never override the Education MCP evidence record.

## Competency focus

For MATH-FRACTIONS, classroom review may consider whether a learner can:

- recognise and compare equivalent fractions;
- solve fraction tasks across assessment and practical contexts;
- explain or justify the method used; and
- transfer fraction understanding to unfamiliar or open-ended problems.

## Interpretation guidance

A candidate longitudinal pattern should remain cautious when evidence types disagree.

- Repeated results across terms can support a bounded pattern.
- Teacher observations can provide important counter-evidence.
- Difficulty explaining a method should not be silently discarded because numerical scores rise.
- Mixed evidence should be represented as uncertainty and counter-evidence for teacher review.
- A pending candidate is not a permanent learner label or profile decision.

The teacher remains responsible for approving, editing or rejecting any candidate interpretation.
