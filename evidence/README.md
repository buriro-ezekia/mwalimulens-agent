# Challenge evidence

This directory contains small, judge-inspectable evidence artifacts that are safe to commit.

## Open-weights run

`open_weights_run.json` is intentionally **not** generated by tests.

Workflow:

1. Run the real local Qwen/Ollama task:
   `python -m mwalimulens.agent.open_weights_run`
2. Confirm the runtime report shows `"status": "pass"`.
3. Promote it:
   `python -m mwalimulens.agent.promote_open_weights_evidence`
4. Review the promoted JSON before committing it.

Promotion is blocked unless every open-weights safety/evidence check is true.

The report stores the prompt, initial/final output and auditable tool metadata. It does not store
hidden chain-of-thought.

## Genuine failures

The `failures/` directory preserves real local-Qwen failures across the workflow-completion,
MCP-lifecycle and candidate-semantics debugging sequence. These files are intentionally retained
as challenge evaluation evidence and include the next attempted remediation.
